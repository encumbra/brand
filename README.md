# Encumbra brand

Logos, icons, social cards and brand guidelines for [Encumbra](https://encumbra.ai): credit for AI
agents, kept honest by code.

The identity is the Imprint wordmark: a serif signature with a joined m and b. There is no
separate symbol. The full rules are in [`guidelines/Encumbra-Brand-Guidelines.pdf`](guidelines/Encumbra-Brand-Guidelines.pdf).

## Files

| Path | What it is |
|---|---|
| `imprint/imprint-{ink,paper,black,white}.{svg,png}` | The outlined wordmark. Ink on paper, paper on ink; black and white are for single-colour print. |
| `logo/avatar-square.svg`, `logo/avatar-circle.svg`, `logo/avatar-square-paper.svg` | The wordmark's capital E, for avatars and app icons where the wordmark cannot fit. |
| `icons/` | Product line icons on a 24px grid. |
| `social/` | Announcement cards, 1080x1080 (one 1600x900). `testnet-live.svg` is for the Base Sepolia launch announcement; use it only once the testnet deployment is live. |
| `guidelines/` | The brand guidelines. |

## Rules

- Leave half the capital-E height clear on every side of the wordmark.
- Minimum width 120px. Scale proportionally; never redraw or respace the letters.
- Pair every state colour with a short text explanation.

## Colour

| Name | Hex | Use |
|---|---|---|
| Ink | `#182921` | Type and dark panels |
| Paper | `#F5F2E9` | Backgrounds |
| Mint | `#C5E9AB` | Actions and emphasis, with ink text on top |
| Ledger Gray | `#D7DBCF` | Rules and tracks |
